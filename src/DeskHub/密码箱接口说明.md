# DeskHub 密码箱接口说明（给要接入的程序）

版本：接口 1（DeskHub 0.4.0 起）

## 是什么
本机的其他程序（比如以后的自动登录工具、脚本）可以向 DeskHub 密码箱要某个网站的账号和密码。**每次都要密码箱主人确认**，主人不点允许，程序就拿不到。

## 安全规则
- **只在本机**：走 Windows 命名管道，不开网络端口、不联网；只有当前 Windows 用户能连，网络来的连接一律拒绝。
- **默认关闭**：在 密码箱 → 更多 → 对外接口 里打开。关闭时管道不存在。
- **要主人确认**：确认框会显示是哪个程序（按管道另一头的进程查出来的真实程序路径，没法冒充）、要哪个网址、给哪一条。选项有「允许这一次」「总是允许」「拒绝」，60 秒不点就算拒绝。
- **"总是允许"只管一个程序取一条记录**，并且绑定程序文件的指纹（SHA-256）：程序被替换或升级后要重新确认。可以随时在「对外接口」里撤销。
- **密码箱锁着**时会弹出解锁界面，说明是谁在要；主人解锁后再确认。2 分钟没解锁就返回 `locked`。
- 一次只处理一个请求；每次取用（包括被拒绝的）都记在「最近取用记录」里。授权和记录跟密码一起加密保存。

## 怎么连
- 管道名：`DeskHub.Vault.<当前用户的 SID>`
  - SID 可以这样取：PowerShell `[System.Security.Principal.WindowsIdentity]::GetCurrent().User.Value`
- 一次连接：发一行 JSON（UTF-8，以换行结尾），收一行 JSON，然后断开。
- 字段名不区分大小写。

### 请求
| 字段 | 说明 |
|---|---|
| `op` | `status` 或 `get` |
| `url` | `get` 用：要登录的网址。按主域名匹配，比如 `https://seller.tiktok.com/login` 能匹配网址是 `tiktok.com` 下的记录；网址完全相同的排在前面 |
| `name` | `get` 用：或者按服务名找（包含即可）。`url` 和 `name` 至少给一个 |
| `reason` | 可选：用途，会显示在确认框里，比如 `"自动登录 TikTok 卖家后台"` |

### 回答
```json
{"ok":true,"app":"DeskHub","api":1,"locked":false}
```
```json
{"ok":true,"credential":{"id":"…","name":"TikTok 卖家后台","url":"https://seller.tiktok.com","account":"shop@xx.id","password":"…","fields":{"支付密码":"…"}}}
```
```json
{"ok":false,"error":"denied"}
```
| error | 意思 |
|---|---|
| `disabled` | 接口没开（通常连都连不上） |
| `bad_request` | 请求格式不对 / 没给 url 和 name |
| `locked` | 密码箱锁着，主人没有解锁 |
| `denied` | 主人点了拒绝 |
| `timeout` | 主人 60 秒没回应 |
| `not_found` | 密码箱里没有匹配的记录 |
| `unknown_client` | 查不出发请求的程序是哪个 |

## 例子

PowerShell：
```powershell
$sid  = [System.Security.Principal.WindowsIdentity]::GetCurrent().User.Value
$pipe = New-Object System.IO.Pipes.NamedPipeClientStream('.', "DeskHub.Vault.$sid", [System.IO.Pipes.PipeDirection]::InOut)
$pipe.Connect(3000)
$enc = New-Object System.Text.UTF8Encoding($false)
$w = New-Object System.IO.StreamWriter($pipe, $enc); $w.AutoFlush = $true
$r = New-Object System.IO.StreamReader($pipe, $enc)
$w.WriteLine('{"op":"get","url":"https://seller.tiktok.com/login","reason":"自动登录"}')
$res = $r.ReadLine() | ConvertFrom-Json      # 会等到主人在确认框里点了按钮
$pipe.Dispose()
if ($res.ok) { $res.credential.account; $res.credential.password }
```

Python（不用装任何库，管道直接当文件打开）：
```python
import json, subprocess
sid = subprocess.check_output(["powershell", "-NoProfile", "-Command",
      "[System.Security.Principal.WindowsIdentity]::GetCurrent().User.Value"], text=True).strip()
with open(rf"\\.\pipe\DeskHub.Vault.{sid}", "r+b", buffering=0) as p:
    p.write((json.dumps({"op": "get", "url": "https://seller.tiktok.com", "reason": "自动登录"}) + "\n").encode())
    res = json.loads(p.readline())
print(res["ok"], res.get("credential", {}).get("account"))
```

## 给接入方的建议
- 拿到的密码用完就丢，不要写进日志、文件或发到网上。
- 先发 `status` 看接口在不在、锁没锁，再发 `get`。
- `get` 要等主人点按钮，读回答时不要设太短的超时（建议 3 分钟）。
