# 版本差异和合并说明（0.18.0 起）

通用版和专用版的差别**只放在本文件夹的两个文件里**：

| 文件 | 管什么 |
|---|---|
| `Edition.props` | 程序文件名、产品名、安装包文件名前缀；可选功能的编译开关 |
| `Edition.cs` | `Brand`（名字、标识、互斥量、管道前缀、本机 Claude 端口、另一个版本是谁）；`Edition`（工具条按钮、分区表、工具条可选项、索引要不要扫 USB 盘） |

专用版只改这两个文件。合并通用版时：**这两个文件留自己的，其余文件冲突一律收通用版的**。
专用版自己的业务功能放在新文件里（例如 `Biz\` 文件夹），在 `Edition.cs` 里接进来（工具条按钮的回调、分区表头按钮的回调），不要改通用版的文件。

## 第一次合并 0.18.0 要做的

1. 原来专用版的品牌常量（产品名、程序名、数据目录、互斥量、端口、另一个版本的名字等）挪进 `Edition.cs` 的 `Brand`：`Name`、`Id`、`ClaudePort`、`Other.Name / Process / SingleMutex / ExitSignal`。互斥量、管道名都由 `Id` 拼出来，不用单独改。
2. `AssemblyName`、`Product`、`AssemblyTitle` 不在 `DeskHub.csproj` 里了，改在 `Edition.props`；`AssemblyName` 要和 `Brand.Id` 一样。
3. 安装程序（`Setup`）也读这两个文件：`Setup.csproj` 导入 `Edition.props`、链接 `Edition.cs`（定义了 `SETUP`，所以 `Brand` 里不能用 WPF 的东西）。安装包文件名是 `SetupFilePrefix_版本号.exe`。
4. 专用版要关的功能在 `Edition.props` 里改成 `false`。

## 可选功能开关（Edition.props）

`FeatArchive` 自动归档、`FeatLocalClaude` 本机 Claude 小服务、`FeatTripAi` AI 识别行程、`FeatVaultApi` 密码箱对外接口、`FeatHotkeys` 全局快捷键、`FeatBalloon` 托盘气泡、`FeatFlow` 事项分类和流转、`FeatCalendar` 日历和定时便签（含备忘录）。

- 关掉的功能连源文件一起不编译，设置里对应的页也没有。
- 依赖：`FeatArchive` 要 `FeatFlow`；`FeatTripAi` 要 `FeatCalendar`。组合不对，编译时直接报错。
- 一直保留：分区、时钟、工具条、布局保存和恢复、多语言、设置、计算器、截图、文件查找、密码箱。
- 发版前检查：`dotnet build -p:AllFeaturesOff=true` 必须能编过。

## Edition.cs 里能改的

- **工具条按钮** `DockButtons`：内置键名 `search shot calc memo calendar vault arrange settings`（本版本没有的功能自动跳过）；自己的按钮写 `new DockButton("键", "字", "20×20 线条图标路径", "说明", t => …)`。要打开某个软件用 `t.OpenApp(路径)`：已经开着就切过去（最小化的先还原），没开才启动，只在托盘里的不再开一个、只在工具条旁轻提示。
- `DockAcceptsShortcuts`：用户能不能把快捷方式拖到工具条上（右键能拿掉）。通用版关。
- `DockNoActivate`：点工具条不抢焦点。`DockExcludeFromCapture`：截图、录屏、共享屏幕时看不见工具条（Win10 2004 以上，旧系统跳过）。通用版都关。
- **分区表** `Fences`：每项是 `FenceSpec(键, 收什么, 标题, 默认位置大小)`，可选 `Hint` 标题栏右边的说明、`Note` 标题下面一直显示的一行、`EmptyHint`、`Sort`、`Side`（两翼留白里放左还是右）、`Column`（铺满三列里放第几列）、`Rank`（列里先后）、`Button`（标题栏上多一个按钮：图标、说明、回调）。
  - “收什么”：`Apps` 快捷方式和系统图标、`Folders` 文件夹、`Today / Active / Cold` 流转的文件（要 `FeatFlow`）、`Files` 全部散放的文件（没有流转时用）。会出现的每种东西都要有一个分区收。
  - 键名存在用户的布局里，改了老用户的位置就丢了。
  - 两翼留白 / 一个大盒子 的分组按 `Side` 自动算，不用另写。
- `IndexUsbDisks`：文件查找要不要扫 USB 接的移动硬盘。通用版扫。

## 通用版里新加的公共接口

- `DeskController.Mover`（`Core\FileMover.cs`）：挪文件统一走这里。`Move(要挪的, 标签)` 返回批号、挪成功的、跳过的（重名自动改名，被占用的跳过并说明原因）；`Undo(批号)` 撤回。所有挪动都记在“移动记录”里（设置 → 移动记录），自动归档也用它。
- `Interop\LocalPipe`：只给本机、本用户的命名管道（拒绝网络身份 + PIPE_REJECT_REMOTE_CLIENTS）。索引程序和密码箱接口都用它，专用版新开管道也用它。
- 设置窗口拆成 `UI\Settings\` 下每页一个文件（实现 `ISettingsPart`）。
